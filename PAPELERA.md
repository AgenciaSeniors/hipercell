# Papelera de productos

1. En Supabase, abre SQL Editor y ejecuta `supabase/08-papelera-hipercell.sql` completo. Debe devolver «Papelera de Hipercell preparada».
2. Sube la versión actualizada a Hostinger y recarga el panel con Ctrl + F5.
3. En Productos, pulsa «Mover a la papelera» y confirma. Desaparece del catálogo y del inventario normal.
4. En Papelera, pulsa «Restaurar». Regresa a Productos oculto; edítalo y marca «Visible en el catálogo» para publicarlo.

Se conservan fotos, precios, stock, categoría e historial. No hay borrado definitivo. Las políticas de acceso existentes siguen protegiendo cada negocio. La restricción de visibilidad se aplica solo a Hipercell. El SQL debe ejecutarse antes de actualizar el panel.
